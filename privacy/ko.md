# 파인노트 — 개인정보 처리방침

**최종 갱신:** 2026-04-25

## 파인노트가 수집하지 않는 것

파인노트는 계정이나 로그인이 필요하지 않습니다. 노트는 다음 위치에 저장됩니다:
- **사용자의 기기** (Core Data, Apple 로컬 데이터베이스)
- **사용자의 iCloud 비공개 데이터베이스** (Apple CloudKit이 관리)

개발자는 노트 본문에 접근할 수 없습니다. iCloud 동기화 데이터에는 Apple iCloud 약관이 적용됩니다.

## 앱 품질을 위해 수집하는 익명 데이터

| 서비스 | 데이터 | 용도 |
|---|---|---|
| **Amplitude** | 익명 기기 식별자, 앱 이벤트명 (예: `note_pinned`, `note_completed`), 세션 길이 | 어떤 기능이 유용한지 파악 |
| **Firebase Crashlytics (Google 제공)** | 크래시 리포트, 성능 지표, OS/기기 모델 | 버그 진단 및 수정 |
| **Google AdMob** | 광고 식별자 (App Tracking Transparency 동의 시에만), 광고 노출·클릭 데이터 | 라이브러리·설정 안에서만 광고 표시 — 잠금화면에는 절대 표시하지 않음 |

## 명시된 제3자

- **Amplitude** — [https://amplitude.com/privacy](https://amplitude.com/privacy)
- **Firebase Crashlytics (Google)** — [https://firebase.google.com/support/privacy](https://firebase.google.com/support/privacy)
- **Google AdMob** — [https://policies.google.com/privacy](https://policies.google.com/privacy)
- **Apple CloudKit** — iCloud 데이터에 Apple 약관 적용

## 앱 추적 투명성 (App Tracking Transparency)

파인노트는 사용자가 광고 표면(라이브러리 또는 설정)에 처음 접근하는 시점에만 ATT 권한을 요청합니다. 거부하시면 AdMob은 비개인화 광고만 표시합니다. iOS **설정 → 개인정보 보호 및 보안 → 추적 → 파인노트**에서 언제든지 변경할 수 있습니다.

## 사용자 권리

- **모든 데이터 삭제** — 파인노트 → 설정 → "모든 데이터 삭제". 기기와 iCloud 비공개 데이터베이스의 노트를 모두 지웁니다.
- **분석 비활성화** — iOS **설정 → 개인정보 보호 및 보안 → 분석 및 개선**에서 OS 차원에서 옵트아웃 가능.
- **광고 추적 비활성화** — 위 ATT 섹션 참조.
- **문의** — [지원 페이지](/pinote-pages/support/ko)

## 데이터 보존 기간

| 종류 | 보존 기간 |
|---|---|
| 노트 | 사용자가 삭제할 때까지 (로컬 또는 "모든 데이터 삭제" 메뉴) |
| 익명 분석 이벤트 | 90일 후 집계·익명화 |
| 크래시 리포트 | 90일 |
| 광고 데이터 | Google AdMob 정책에 따름 (위 링크) |

## 아동의 개인정보

파인노트는 4세 이상 등급이지만 13세 미만 아동을 대상으로 하지 않습니다. 아동의 개인정보를 알면서 수집하지 않습니다.

## 정책 변경

처리 방침이 변경되면 본 페이지를 갱신합니다. 페이지 상단의 "최종 갱신" 날짜가 최신 개정일을 나타냅니다.
