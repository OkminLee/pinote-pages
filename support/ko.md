# 파인노트 — 지원

도움이 필요하신가요?

- **이메일:** pinote@okm.studio
- **버그 리포트 또는 기능 요청:** [GitHub Issues](https://github.com/OkminLee/pinote-pages/issues)
- **응답 시간:** 보통 48시간

## 자주 묻는 질문

**iPad / Apple Watch 에 노트가 동기화되지 않아요.**
- 두 기기가 같은 iCloud 계정으로 로그인되어 있는지 확인하세요
- 파인노트의 iCloud Drive 가 켜져 있는지 확인 (iOS 설정 → [내 이름] → iCloud)
- Live Activity 푸시가 도착할 때까지 최대 30초 기다려주세요

**모든 데이터는 어떻게 삭제하나요?**
파인노트 → 설정 → "모든 데이터 삭제". 기기와 iCloud 비공개 데이터베이스의 노트를 모두 지웁니다.

**광고는 어떻게 끄나요?**
파인노트의 광고는 라이브러리와 설정 안에서만 표시됩니다. 잠금화면·Live Activity·Dynamic Island·위젯·Apple Watch 어디에도 광고가 뜨지 않습니다. 향후 업데이트에서 광고 제거 Pro 등급이 나올 예정이며, 초기 가입자는 평생 무료로 이용 가능합니다.

**오랫동안 사용하지 않으면 Live Activity 가 사라져요.**
iOS Live Activity 는 시스템 정책상 시간 제한이 있습니다 (보통 8시간 비활성). 파인노트는 다음에 앱을 열 때 자동으로 다시 핀합니다. Live Activity 가 멈춘 것 같으면 파인노트를 강제 종료 후 다시 열어주세요.

**다른 앱에서 노트를 가져올 수 있나요?**
v1 에서는 지원하지 않습니다. 파인노트는 의도적으로 미니멀합니다 — 일반 텍스트와 체크리스트만 저장합니다. 직접 복사 붙여넣기로 옮길 수 있어요.
